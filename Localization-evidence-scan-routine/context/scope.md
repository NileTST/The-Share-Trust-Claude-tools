# Scope

- Search only the sources listed in `sources.md` — never add a source on your own initiative.
- Search window: the prior calendar month only.
- `guidance.md` defines what to look for. Update only via commands, never on your own initiative.
- Never process PII, participant data, or confidential/partner-sensitive data. If a request would require this, decline and flag it per `ai-policy.md`.
