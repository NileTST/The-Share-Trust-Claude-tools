# Output Format

- Length: ~3 pages.
- Structure: organized by theme first. Cross-cutting themes (appearing in 2+ sources) listed at the top. Within each theme, break down findings by source.
- Header states the timeframe covered (e.g., "Sources reviewed: [Month Year]") and lists sources reviewed.
- Every finding states which source it came from.
- Distinguish source findings from opinion. If opinion is included, label it explicitly as opinion.
- Save the finished summary to `reports/YYYY-MM-evidence-scan.md` in this repo (year-month of the period covered), and commit it.
